# 双休购 · Weekend First

> 用每一次消费，为**善待员工**的企业投票。

一个「支持双休企业」的纯前端 PWA 应用：收录真正实行上四休三 / 四天半 / 双休的企业及其商品，像京东淘宝一样完整下单；同时曝光压榨员工的反面教材。买谁的、抵制谁的，一目了然。

## ✨ 功能特性

### 🛒 完整电商流程
- **商品库**：323 个商品，覆盖数码、家电、服饰、美妆、食品、母婴、家居、汽车、图书、游戏、教育、旅游等 13 大分类
- **关键词配图**：按商品名智能匹配真实商品图（69 张本地图，零外链）
- **购物车**：增减数量、删除、满减进度条
- **下单结算**：收货地址、手机号校验、多种支付方式
- **优惠券**：自动匹配最优券，订单显示省了多少
- **订单全生命周期**：待付款 → 待发货 → 已发货（多节点物流时间线 + SVG 路线图）→ 待收货 → 待评价 → 已完成
- **售后**：退货/换货/仅退款/维修，客服处理
- **商品评价**：星级评分 + 文字评价，提交后进入商品评论区
- **收藏商品 / 最近浏览 / 商品对比**（最多 4 个并排参数对比）

### 🏢 企业数据库
- **109 家双休企业**：含政策标签（上四休三 / 四天半 / 双休 / 弹性）、薪资水平、休息天数、城市、行业
- **31 个反面教材**：均有新华社、央视网、澎湃新闻等权威媒体公开报道，附事件年份与证据
- **企业详情页**：作息表可视化、薪资区间、在招岗位（应聘入口）、全部商品
- **每周休息天数总榜**：休息越多排越前

### 🎨 体验
- **深色模式**一键切换，localStorage 记忆
- **动态效果**：数字滚动、卡片悬停、图片轮播、物流脉冲动画
- **价格走势迷你图**：商品详情展示近 30 天 SVG 折线图
- **搜索联想**：输入实时出商品建议，聚焦显示搜索历史 + 热搜词
- **每日签到领积分** + 4 级会员体系
- **新人礼包弹窗**：首次访问送积分 + 优惠券
- **客服悬浮按钮**、回到顶部、PWA 离线缓存、可安装到桌面

## 🛠 技术栈

- **纯原生**：HTML + CSS + JavaScript（无框架、无构建工具）
- **PWA**：Service Worker 离线缓存 + Web App Manifest + 可安装
- **路由**：hash 路由 SPA
- **存储**：localStorage（购物车、订单、地址、收藏、积分、对比、搜索历史）
- **图标**：手写 SVG logo + 多尺寸 PNG
- **数据**：分层 JS 数据文件（data.js → data2.js → data3.js → data4.js）

## 🚀 本地运行

无需构建，直接打开或起个静态服务器：

```bash
# 方式一：直接双击 index.html
# 方式二：起个静态服务
npx serve .
# 或
python -m http.server 8080
```

然后浏览器访问 `http://localhost:8080`。

## 🤝 贡献

欢迎补充双休企业信息、反面教材证据、商品数据。数据都在 `js/data*.js` 里，按现有工厂函数格式添加即可：

```js
// 企业：comm(id, 名称, 简称, 首字母, 主题色, 行业, 城市, 域名, 简介, 商品数组, 额外信息)
// 反面教材：bad(id, 名称, 简称, 颜色, 行业, 城市, 问题, 严重度, 状态, 年份, 简介, 薪资说明, 证据, 商品)
// 商品：p(名称, 主分类, 细分类, 描述, 是否热门)
```
